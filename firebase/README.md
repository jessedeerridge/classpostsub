# city2 の Firebase 保存先

既存の Realtime Database 内の `buidings/posts` を、city2 の画像投稿専用に使います。city1 は `shusshinSentence/posts` のままです。トップは ito に変更しました。

Firebase コンソールでプロジェクト `database-s-9e4b3` を開き、Realtime Database → ルールに `database.rules.json` の内容を貼り付けて公開してください。既存の保存先のルールは維持しています。このルールはログインなしの読み書きを許可します。

保存先 `buidings` は、ルール公開後の最初の投稿で自動的に作成されます。手動で空のノードを作る必要はありません。既存の端末内の画像投稿は、新しい保存先へ再送するようにしています。

このファイルを GitHub に置くだけでは、Firebase のルールは変更されません。ルールの公開は Firebase コンソールで行ってください。

## ito の数字配布

トップと `ito/index.html` は共通の `ito/players` を使います。上記のルールを公開すると利用できます。数字は開始時に1〜100から選びます。全プレイヤーを対象とするトランザクションで配布するため、同時に押しても重複しません。引き直しは前の数字を除いて選び、取得と返却を一括で確定します。空きがない場合は現在の数字を維持します。

接続ごとに別のIDを発行し、配布前に `onDisconnect().remove()` を登録します。サーバーが切断を検知すると数字が戻ります。突然の通信断では検知まで時間がかかります。再接続後は「開始」から引き直します。数字を持たない接続は0で登録し、デッキを消費しません。切断済みIDを配布処理が復活させることはありません。

既存ページと同様、認証のない共有ゲームです。他の人の数字は画面には表示しませんが、データへのアクセス権限で秘匿する設計ではありません。
